# Reporting a Bug

If you encounter a bug, please report it by using the feedback button and then sending an email to our support team at [help@bluefla.me](mailto:help@bluefla.me). Make sure to include detailed information about the issue, including steps to reproduce the bug, any error messages you received, and the environment in which the bug occurred (e.g., operating system, browser version). This will help us address the problem more efficiently.
