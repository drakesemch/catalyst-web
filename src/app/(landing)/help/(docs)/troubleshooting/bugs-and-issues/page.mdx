# Coming across bugs and issues

Coming across a bug or issue in Catalyst, at least in this early stage of development, is not uncommon. This page will help you understand how to report these issues, and how to troubleshoot them.

## Specific Issues

- [Page not loading](/help/troubleshooting/page-not-loading)
- [Application error: a client-side error occured (see the browser console for more information).](/help/troubleshooting/client-error)
- [Canvas needs Attention](/help/troubleshooting/canvas-needs-attention)

## Reporting Bugs

If you come across a bug in Catalyst, click on a report button near the bottom right of your screen, and fill out the form. This will send a report to the developers, and they will work on fixing the issue. Using this form will provide additional feedback and context to the developers, which will help them fix the issue faster. Using the platform, errors will automatically be sent, but using the form, will ensure that these issues get fixed.
