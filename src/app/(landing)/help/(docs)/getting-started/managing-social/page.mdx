# Managing Friends and Groups

Managing your social is a difficult task on any platform. With Catalyst, you simply click on view profile to manage a user, and to add a user, scroll down to the bottom and find requests, there you will find a prompt to add a user by their email. To manage groups, click on the groups tab and you will be able to create a group, add users to a group, and manage the group settings. You can block, and dismiss friend requests to stop further requests from being placed.
